Import safety
Use UTF-8 CSV. The file limit is 2 MB and the row limit is 200. The entire import is rejected if any row fails validation. Do not include passwords, tokens, secrets, or unnecessary personal information.

Recommended import sequence

Use a controlled, repeatable process.

1. Download the current template
Templates may evolve as domain rules and required fields change.
2. Keep identifiers and enums consistent
Use the exact date format YYYY-MM-DD and allowed enum values shown by the workspace.
3. Test a small batch first
Review the first import and confirm owners, due dates, and record keys before importing a larger batch.
4. Review audit history
Imported records receive keys and creation events. Keep the source file under your retention policy.

CSV formatting rules

Common errors to avoid.

Encoding
UTF-8 or UTF-8 with BOM.
Dates
Use ISO dates, for example 2026-10-24.
Numbers
Use plain decimals without currency symbols or thousands separators.
Booleans
Use clear true/false values for checkbox fields.
Quotes and commas
Let a CSV writer quote values containing commas, quotes, or line breaks.
Formula safety
Exports neutralize formula-leading cells; avoid entering spreadsheet formulas as data.
