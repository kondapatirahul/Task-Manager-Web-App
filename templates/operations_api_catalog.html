Request conventions

Shared behavior across API routes.

Authentication
Existing Flask-Login session is required.
Write protection
Send the CSRF token in the X-CSRFToken header for state-changing requests.
Response envelope
Successful JSON responses use ok=true and a data object; errors use ok=false and an error message.
Pagination
List APIs accept page and page_size; page sizes are bounded by the server.
Tenant isolation
Queries are scoped to the current organization, except for explicitly authorized super-admin operations.

Integration checklist

Before connecting an external consumer.

Example create request

Use the module-specific required fields from the workflow matrix.

Example payload for an incident record. The exact required fields depend on the module policy.

{
  "title": "Public API elevated error rate",
  "summary": "Errors increased after the latest deployment.",
  "priority": "high",
  "due_date": "2026-10-25",
  "service": "Public API",
  "environment": "production",
  "impact": "high",
  "urgency": "high",
  "reported_by": "Monitoring"
}

Send the JSON body with Content-Type: application/json and the session CSRF token in X-CSRFToken. A successful create returns HTTP 201 and the record in the data field.

Example success envelope

Clients should inspect HTTP status and the response envelope.

{
  "ok": true,
  "message": "Record created.",
  "data": {
    "id": 42,
    "key": "INC-00042",
    "module": "incidents",
    "status": "new",
    "priority": "high",
    "version": 1
  }
}

The example is illustrative. Actual IDs, keys, timestamps, and fields are generated by the server and must not be assumed in clients.

Error handling reference

Common failure classes and the recommended client behavior.

HTTP statusMeaningRecommended behavior
400Invalid input, unsupported enum, malformed identifier, or invalid date.Show the field or request error and ask the user to correct it.
401Authentication is missing or expired.Return the user to sign-in and preserve a safe local navigation target.
403The caller does not have the required role or permission.Do not repeatedly retry; explain that a manager or administrator action is needed.
404The record is missing or outside the caller's visible organization scope.Refresh the list and avoid revealing cross-tenant record existence.
409Workflow transition conflict, duplicate assignment, or stale record version.Reload current state and ask the user to reapply their change intentionally.
413The CSV import exceeds the supported file size.Split the input into smaller batches and preserve the source file.
422One or more domain fields failed validation.Read the fields/rows error details and fix all reported values before retrying.
500Unexpected server-side failure.Use a correlation or request ID if available; do not expose stack traces to end users.
